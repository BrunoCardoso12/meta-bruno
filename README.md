
# Meta Bruno

Camada personalizada do Yocto Project para desenvolvimento e aprendizado de sistemas Linux embarcados.

## Objetivos

- Desenvolver receitas personalizadas para o Yocto Project.
- Adicionar serviços e aplicações ao sistema Linux.
- Explorar customizações de imagens embarcadas.
- Estudar a organização e o funcionamento de camadas OpenEmbedded.

## Compatibilidade

- Yocto Project 6.0 (Wrynose)
- OpenEmbedded
- BitBake

## Estrutura

```text
meta-bruno/
├── conf/
│   └── layer.conf
├── recipes-example/
├── LICENSE
└── README.md
```

## Desenvolvimento

Esta camada está em desenvolvimento e será utilizada como ambiente de aprendizado e experimentação com o Yocto Project.

As receitas e funcionalidades serão adicionadas gradualmente.
